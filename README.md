# 📚 Sistema de Biblioteca

Sistema simples de gerenciamento de acervo com persistência em JSON.

## Funcionalidades
- ✅ Cadastro de livros
- ✅ Listagem com ordenação
- ✅ Busca flexível (ignora maiúsculas/minúsculas)
- ✅ Empréstimo e devolução
- ✅ Remoção com confirmação
- ✅ Contador de acervo
- ✅ Dados salvos em JSON

## Como executar
```bash
python projeto_biblioteca.py
